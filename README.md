# Estante Virtual — Mestrado PPGHCA

Portal de conteúdos acadêmicos do Programa de Pós-Graduação em Humanidades, Culturas e Artes (PPGHCA) da Unigranrio Afya.

🔗 **Publicado em:** [https://eduardobbastos.github.io/estante_mestrado](https://eduardobbastos.github.io/estante_mestrado)

## Disciplinas

- [Estudos de Cultura Brasileira](EstudosCulturaBrasileira/)
- [Metodologia da Pesquisa](MetodologiaPesquisa/)

## Estrutura

```
estante_mestrado/
├── index.html          → Portal com links para as disciplinas
├── EstudosCulturaBrasileira/
│   ├── index.html
│   ├── config.env
│   └── assets/
│       ├── css/style.css
│       └── js/
│           ├── main.js
│           └── modules/
│               ├── Config.js
│               ├── DataService.js
│               ├── UIComponents.js
│               └── Utils.js
└── MetodologiaPesquisa/
    └── ... (mesma estrutura)
```

## Tecnologias

- HTML5 + CSS3 puro
- JavaScript modular (ES Modules)
- [Lucide Icons](https://lucide.dev/)
- Integração com Google Sheets (via CSV export)
